# @agimon-ai/doompi-runner-rtk-darwin-x64

Prebuilt RTK v0.45.0 log processor for Intel macOS (`darwin-x64`).

[`@agimon-ai/doompi-runner`](https://www.npmjs.com/package/@agimon-ai/doompi-runner) declares this package as an optional dependency. Install Runner rather than this artifact directly.

The package contains the RTK binary from upstream tag `v0.45.0` at commit `b34be37caf3796b69a50952a28e60e32b5daad43`. It exports only package metadata and has no JavaScript runtime API.
